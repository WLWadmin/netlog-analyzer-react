# 【外部】网络问题信息收集 副本

收到文档网络相关的问题反馈时，为了高效解决问题，同时避免多次沟通带来的用户打扰，尽可能一次性收集全网络相关的基本信息和日志

# 网络信息

麻烦按照「如何操作」进行网络信息收集，并发送给飞书客服

要收集的信息如下

- 客户端IP/DNS出口

- 确定打不开的域名或者请求慢的域名

- 域名对应的 DNS/IP连通性/丢包率/路由信息确认

- 上网方式\\环境信息收集

## 确定打不开的域名或者请求慢的域名

### 文档打不开

- 文档主域名打不开，访问文档URL，出现如下情况，直接页面打不开，则确定打不开的域名即是文档主域名。

    - 例如 URL 为 https://abc\.feishu\.cn/docx/xxx  则文档主域名为 abc\.feishu\.cn

![Image](https://api3-eeft-drive.larkoffice.com/space/api/box/stream/download/authcode/?code=MzkxZWZiNGZjN2I2MjczZGEzOTQ3OWNmMDlkYTVkZWJfYWM4ZmE5ODk4YjRiNWMwMGU1MGQwMTdiZjA4ODk0NzFfSUQ6NzY0OTY2NTY5OTI4NzYwMDA4Nl8xNzgxMDc2NjQxOjE3ODExNjMwNDFfVjM)

### 文档打开慢

- 文档可以打开，打开的过程中访问非常慢，加载8s 以上才可以看到页面

    - 键盘 F12 打开 chrome devtools, 最上层 tab 选择 network，刷新文档，等加载完成后，导出 \.har 文件

![Image](https://api3-eeft-drive.larkoffice.com/space/api/box/stream/download/authcode/?code=NWYxNzkxZDgyMjg1NWE5MjJjNzVhODQyOGY1ZWVjYTlfNTRiNzkzNWRkZjY5OWJiMzM0YjNkMTc4OTUxMDE4MTVfSUQ6NzY0OTY2NTcwMzQyMjg1NjEzMF8xNzgxMDc2NjQxOjE3ODExNjMwNDFfVjM)

如果无法导出文件，可以直接截图，如果导出了文件，可以忽略此步骤

- 在 Name 栏目，鼠标右键，选择 Domain 和 remote Adress， 把这两个信息栏打开

![Image](https://api3-eeft-drive.larkoffice.com/space/api/box/stream/download/authcode/?code=MDRkMDY5ZjcwNTljNzNhOTVlM2M0ZDNkOWQ3NjY4ZjBfZmMwMzNmYTQyYTYwNjk1NzY5MThkYjc1MzU0NDliZThfSUQ6NzY0OTY2NTcwNDA3NTQ5NjQxN18xNzgxMDc2NjQxOjE3ODExNjMwNDFfVjM)

- 观察 Time 栏目，把 Time 栏目里面 1s 以上的请求，记录下来，记录这条记录的 Domain 和 RemoteAddress。记录结果，发给排查人员
