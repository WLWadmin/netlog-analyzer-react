# D · PRD与UI/UX修订

评审稿2.0。方向C已明确：普通用户和工程师共用事实、诊断及证据系统；C1为推荐方案，生产界面尚未批准。本稿连同逐项矩阵构成范围基线，旧合成原型不是功能白名单。

## 用户、问题及成功标准

普通用户/一线支持先理解打不开、失败、慢或卡顿的现象、影响、证据边界和可执行下一步。前端复核HAR Timing、缓存、Trace任务与渲染；后端复核HTTP结果、自报指标及服务侧证据；IT/网络工程师复核DNS、代理、连接、TLS、协议和source关系。

成功要求：原有实际能力全部可达；确定事实可追溯；最终失败与内部失败区分；未知不变为零；无变化不排除原因；Worker/Dataset性能不退化；原始文件默认留在浏览器；导出安全且保留格式；重大变化经过批准。

不新增云端AI、自动上传、账户/后端、原生客户端、移动端适配或技术栈迁移。Go维持项目专用服务日志分析，非通用平台。

## C1信息架构与入口

| 一级工作区 | 普通阅读 | 工程师及来源专属入口 |
|---|---|---|
| 文件与准备 | 导入、可选问题、阶段/取消、质量与缺失 | 格式确认、parser模式、采集指引、配对追加、Dataset状态和资源管理 |
| 诊断概览 | 发生了什么、影响、依据、未知、下一步 | 原有结论/问题组/覆盖/完整诊断，直接跳真实对象 |
| 请求与任务 | 失败/慢对象与详情 | NetLog请求与生命周期；HAR完整筛选/瀑布/九详情；Trace网络/任务；Go完整流程 |
| 证据复核 | 当前问题的支持、冲突与限制 | 原始HAR、全量Events、Source Chain、Raw Event、坐标/版本/字段、Go原日志 |
| 专家分析 | 按需展开，常驻可发现入口 | NetLog九入口及十一状态；Trace正式七视图和原有flag控制的内部工作台 |
| 行动与交付 | 顺序、角色、预期、实际、回退、安全分享 | 完整报告、验证记录、既有导出格式与授权证据配置 |
| 联合与比较 | 为什么能/不能关联或比较 | 双方独立数据、匹配/覆盖/冲突/未匹配，HAR/NetLog/Combined三A/B模式 |

减少一级菜单只是重组。每个矩阵Feature ID有明确新入口；所有原有查询条件、排序、字段、交互和数据范围保持。高级内容不以身份选择为前提，不从正式变实验。

NetLog专家内容明确保留Data Loaded、Events、Source Chain、Timeline、安全与协议、网络状态、性能、A/B、完整报告；状态保留DNS、Proxy/PAC、Sockets、HTTP/2、QUIC、Cache、Alt-Svc、Stream Pool、Reporting、Modules、Prerender。SSL/TLS及Protocol独立分析不因状态视图存在而取消。

HAR详情保留Headers、条件Payload、Preview、Response、Initiator、Timing、Cookies、Network、诊断；Query及postData仍在其原有语义位置。恢复质量、隔离记录和未恢复片段有常驻入口。Raw有限预览如实说明范围，Dataset全量能力不变成有限预览。

Trace正式七入口保留结论、概览、网络、主线程、渲染、交互、全部证据。Workbench→Timeline→Expert→Cross-source→Stage5→Stage6保持现有逐层开关语义、默认值与代码，不因原型省略而关闭。七个公开页面与内部能力分别标注。

## 八类界面与关键状态

1. 导入与准备：直接文件选择/拖拽不加必填身份；主路径仍单文件，组件multiple及现有双源追加保持。不宣传任意多文件融合。正常、部分恢复、不支持、截断、取消、失败、会话过期分别显示。
2. 诊断概览：问题/影响/支持/反证/未知/下一步优先，统计不挤占主要问题。无异常写“本次采集未发现受支持的异常”，同时保留覆盖限制。
3. 请求与任务：列表联动详情，所有原筛选和排序可访问；自身完整生命周期、观察下界与关联操作分栏。HAR TLS包含关系、自报指标和wait语义可见，不能强行相加成三段。
4. 证据复核：来源、真实ID、单位/基准/区间/版本可见；按需详情和全量分页共存。目标被过滤时临时显现并提示；目标不存在明确失败。
5. 专家分析：可从导航直接进入，也可沿当前证据深入；状态计数、分页、source/chain/raw跳转保留，缺能力明确提示。
6. 行动与验证：命题、角色、前提、单一改变、预期、实际、含义、不能证明和回退齐全；改善仅支持方向，无变化不排除原因，变差先回退。
7. Combined/A-B：双方原始入口、匹配理由/时间误差/覆盖/冲突/未匹配和真实比较对象；不以静态卡片替换加载和查询。
8. 安全导出：选择既有格式和配置、同DTO预览再下载、稳定证据别名及限制说明；本地完整字段与分享字段分开。专家授权范围待负责人决策。

关闭抽屉、详情或Esc保留选中对象和窗口。跨视图跳转保存筛选、排序、时钟、选区、来源、scroll/focus及会话；返回恢复。历史Hash按现有hashRouting的全部规则兼容，映射记录附在矩阵包中。

## 桌面视觉及原型约束

1440×900采用列表/详情/证据多栏；1280×800允许两栏；1024×768采用列表加覆盖详情，同时恢复列表状态。仅桌面浏览器为本轮门槛。复用Ant Design和系统字体/主题token，石墨色、1px边界、克制层级，不使用外部字体、彩色阴影或backdrop-filter。

键盘选中、焦点返回、可访问名称、完整错误码和长字段本地访问、颜色之外的状态文本属于每阶段验收。紧凑表格不压缩重要操作目标。

旧[高保真合成原型](prototype/index.html)保留作为布局与主流程参考；它没有实现矩阵中的全部功能，不是生产实现，不证明新UI功能完整。固定请求/事件、未覆盖专家页面和不存在目标处理仅是演示边界。矩阵逐项标为“原型未逐项实现”，后续生产授权前补全相关交互及真实入口验证。
